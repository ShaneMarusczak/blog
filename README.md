# Blog

A static blog for GitHub Pages, generated by a tiny Python script. No
frameworks and no runtime JavaScript — every page is plain static HTML.

## How it works

`tools/build.py` wraps shared templates around per-post content to produce the
finished pages. You edit the sources; the script writes the output.

```
SOURCES (edit)                        GENERATED (commit, don't hand-edit)
posts.json           ─┐
content/posts/*.html ─┼─ build.py ─▶  index.html
templates/*.html      │               posts/*.html
partials/*.html      ─┘               feed.xml, sitemap.xml, robots.txt
```

## Adding a post

1. Write the body in `content/posts/YYYY-MM-DD-slug.html` — the inner HTML of
   the article, with **no** `<h1>` and no meta line (the build adds those).
2. Add an entry to `posts.json`:

```json
{
  "file": "2026-02-23-your-post-slug.html",
  "title": "Your Post Title",
  "date": "2026-02-23",
  "category": "your-category",
  "description": "A short summary of the post.",
  "keywords": "tag1, tag2, tag3"
}
```

3. Build, then commit the sources **and** the generated output:

```bash
python3 tools/build.py
```

GitHub Pages serves the committed files directly — there's no build on their
end, so the generated HTML has to be committed.

## Validating

```bash
python3 tools/validate.py
```

Confirms `posts.json` is well formed, each entry has a matching content
fragment, and nothing is orphaned. CI also rebuilds and fails if any committed
page is out of date with the sources.

## Local preview

```bash
python3 -m http.server
```

Then open the printed URL.

## Structure

```
posts.json               front matter (edit)
content/posts/*.html     article bodies (edit)
templates/*.html         page shells (edit)
partials/*.html          shared masthead + footer (edit)
tools/build.py           the generator
tools/validate.py        source checks
base.css                 reset, body, masthead, footer (every page)
style.css                landing page
posts/post.css           posts
index.html               generated
posts/*.html             generated
feed.xml sitemap.xml robots.txt   generated
```
